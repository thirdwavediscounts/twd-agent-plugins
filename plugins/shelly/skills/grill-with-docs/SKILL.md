Call the Skill tool twice, for "grilling" and "domain-modeling".

Before the first round, settle the **docs home** for this piece of work (see domain-modeling's "Where docs go"): app-scoped → `apps/<x>/docs/<feature>/`, cross-cutting or personal → `docs/<project-or-feature>/`. Decisions, notes, and the eventual spec all accumulate there as the interview proceeds — not only CONTEXT.md/ADR updates.
