### Prototype

A throwaway that settles one question by running it.

1. State the question as a checkable observation ("does the list re-render under 16ms with 5k rows?").
2. `/shelly:prototype`: one command to run, smallest scope that answers the question, no production wiring.
3. Run it; record the observation verbatim.
4. Decide from the observation; delete the prototype or keep it by explicit decision, never by drift.
